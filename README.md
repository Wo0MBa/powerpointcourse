# Power Point с Феей русского

Видеокурс по интерактивным презентациям в PowerPoint от @russiangel.

## Как опубликовать на GitHub Pages

1. Создайте на github.com новый **публичный** репозиторий (New repository), например `power-point-kurs`.
2. Нажмите **Add file → Upload files** и перетащите в окно всё содержимое этой папки: `index.html`, `README.md` и папки `c`, `m`, `t`, `v`.
3. Нажмите **Commit changes** и дождитесь окончания загрузки (видео весят около 230 МБ, это займёт время).
4. Откройте **Settings → Pages**. В пункте *Source* выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
5. Через 1–3 минуты вверху этой страницы появится ссылка вида `https://ваш-логин.github.io/power-point-kurs/`. Её и отправляйте ученикам.

## Что где лежит

- `index.html` — сам сайт курса
- `v/` — видео уроков (разрезаны на части до 15 МБ, плеер склеивает их сам)
- `c/` — обложки уроков
- `m/` — фото, ролик с играми, шпаргалки
- `t/` — превью слайдов шаблонов
